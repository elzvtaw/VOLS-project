# Система учёта ВОЛС

Учебный проект (итоговая работа по Python, Flask): веб-приложение для автоматизации подготовки данных
и расчётов к договорам временного ограниченного пользования инфраструктурой АО «ИЭСК» для размещения
ВОЛС операторами связи.

## Этапы проекта

1. **Анализ данных.** Подготовка исходных данных, расчёт протяжённости участков и расстояний между опорами,
   группировка по КТП и классам напряжения. Анализ выполняется с использованием `numpy`, `pandas` и `matplotlib`.
2. **Разработка веб-приложения.** Создание сайта на Flask для ведения участков ВОЛС, операторов связи,
   тарифов и расчётов стоимости пользования инфраструктурой. После разработки приложение размещается на хостинге.

## Структура

```text
vols-accounting/
├── data/

│   ├── operators.csv           # операторы связи и их ID
│   ├── tariffs.csv             # тарифы по классам напряжения
│   └── summary_by_voltage.csv  # сводка по классам напряжения
└── README.md
```

## Происхождение данных

| Файл | Источник |
|---|---|
| `sections.csv` | Таблица «Акт сверки 65-ВЭС-25», результаты выездной сверки от 18.05.2026. |
| `support_spans.csv` | Формулы в столбце «Протяжённость, км» исходного Excel-файла; слагаемые формул перенесены как расстояния между опорами в метрах. |
| `operators.csv` | Список операторов, пользующихся услугой. ID операторов постоянны в пределах этого набора данных. |
| `tariffs.csv` | Тарифы (руб./км) для классов напряжения 0,4; 6; 10; 35; 110; 220 кВ. |
| `summary_by_voltage.csv` | Сводные показатели, рассчитанные по `sections.csv`. |

## Описание `sections.csv`

Первый столбец — `ktp` (КТП); далее указаны напряжение, линия 10 кВ, фидеры, протяжённость, примечания и условные `operator_id`.

Одна строка соответствует сочетанию **КТП + фидер** (для записей с несколькими фидерами они перечислены вместе).
Отдельного `section_id` нет: для идентификации записи используются `ktp` и `feeders`.

| Поле | Описание |
|---|---|
| `voltage_kv` | Класс напряжения: 0.4 или 10 кВ |
| `line_10kv` | Линия ВЛ-10 кВ, к которой относится участок |
| `ktp` | Номер КТП; основной ключ группировки |
| `feeders` | Фидеры, на которых размещена ВОЛС |
| `length_km` | Суммарная протяжённость участка, км |
| `notes` | Объединённые примечания из исходной строки и примечания к блоку |
| `operator_id` | ID одного или нескольких операторов; несколько ID разделены точкой с запятой. Сейчас назначения условные и требуют замены после получения подтверждённых данных. |

## Описание `support_spans.csv`

Каждая строка соответствует промежутку между двумя соседними опорами. Слагаемые формул сопоставлены опорам последовательно; если слагаемых меньше, недостающие расстояния заполнены нулём. Столбца `mapping_status` нет.

Одна строка — одно слагаемое формулы протяжённости, то есть расстояние между соседними опорами.

| Поле | Описание |
|---|---|
| `ktp` | КТП |
| `line_10kv` | Линия ВЛ-10 кВ |
| `feeder` | Фидер или группа фидеров |
| `support_from` | Начальная опора |
| `support_to` | Конечная опора |
| `distance_m` | Расстояние между опорами, м |
| `distance_km` | То же расстояние, км |

Если число слагаемых в формуле не совпадает с числом промежутков между перечисленными опорами, расстояния сохранены,
но `support_from` и `support_to` оставлены пустыми. Такие строки помечены `требует проверки по исходной схеме`,
чтобы не приписывать расстояние неверной паре опор.

## Тарифы

В `tariffs.csv` напряжение 0.4 кВ хранится как `0.4`, остальные классы напряжения — целыми числами
(6, 10, 35, 110, 220), без окончания `.0`.
