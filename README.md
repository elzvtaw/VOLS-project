# Система учёта ВОЛС

Учебный проект (итоговая работа по Python, Flask): веб-приложение для автоматизации подготовки данных
и расчётов к договорам временного ограниченного пользования инфраструктурой АО «ИЭСК» для размещения
ВОЛС операторами связи.

В этом репозитории — данные для анализа (numpy, pandas, matplotlib) и последующей разработки сайта.

## Структура

```
vols-accounting/
├── data/
│   ├── sections.csv            # участки ВЛ с протяжённостью (реальные данные)
│   ├── operators.csv           # операторы связи и их ID
│   ├── tariffs.csv             # тарифы по классам напряжения
│   └── summary_by_voltage.csv  # сводка по классам напряжения
└── README.md
```

## Происхождение данных

| Файл | Источник |
|---|---|
| `sections.csv` | Таблица «Акт сверки 65-ВЭС-25» (акт БДР от 23.10.2025, результаты выездной сверки от 18.05.2026), столбцы «Инфраструктура АО «ИЭСК»» и «Протяжённость, км». Данные предоставлены организацией, разрешение на использование получено. |
| `operators.csv` | Список операторов, пользующихся услугой. ID присвоены произвольно. |
| `tariffs.csv` | Тариф (руб./км) для каждого класса напряжения: 0,4; 6; 10; 35; 110; 220 кВ. |
| `summary_by_voltage.csv` | Рассчитано по `sections.csv`. |

## Описание `sections.csv`

| Поле | Описание |
|---|---|
| `section_id` | Идентификатор записи (S001, S002, …) |
| `voltage_kv` | Класс напряжения: 0.4 или 10 |
| `line_10kv` | Для ВЛ-0,4 кВ — ВЛ-10 кВ, от которой запитана КТП (по таблице сверки). Для ВЛ-10 кВ — сама линия |
| `ktp` | Номер КТП (только для ВЛ-0,4 кВ) |
| `feeders` | Фидеры (Ф.), на которых размещена ВОЛС |
| `poles` | Номера опор, как в исходной таблице (очищено от лишних пробелов и знаков) |
| `length_km` | Протяжённость, км |
| `inline_note` | Пометка из скобок в исходной строке (например, «совмещ. с Ф-3») |
| `block_note` | Примечание из столбца «Примечания» к блоку, в который входит запись |
| `data_flag` | Метка качества данных (см. ниже) |
| `source_row` | Номер строки в исходном Excel — для проверки |

## Известные особенности данных

- **Привязки участков к операторам нет.** В исходных документах не указано, какой оператор какой участок
  использует, поэтому в `sections.csv` нет `operator_id`. Связь «участок — оператор» будет добавлена
  отдельной таблицей, когда появятся данные.
- `no_length_to_verify` (S038, S049) — в исходной таблице для записи нет протяжённости; помечено «сверить».
- `parent_line_unknown` (S049) — перед записью в исходной таблице нет заголовка ВЛ-10 кВ.
- `length_for_group_of_feeders` (S050, КТП-1-838) — в исходной таблице одна протяжённость (0,7684 км)
  указана для Ф-1, Ф-2 и Ф-4 вместе, поэтому это одна запись. Примечание к блоку: участок учтён в АБДР 67-ВЭС-25.
- В записях S015–S016 в акте БДР и в результатах сверки указаны разные ВЛ-10 кВ; взяты данные сверки.
- В `poles` сохранены обозначения как в источнике (диапазоны «4 – 7», дополнительные опоры «6/1» и т. п.),
  количество опор из них автоматически не считалось.
- PDF со схемами в репозиторий не включён.
